# 创作与 AI Skill 工作库

一个仓库，按用途分区；作品与教 AI 做事的 Skill 分开保存。这里不是得到大脑或 Obsidian 的整库备份。

| --- | --- | --- |
| 社交内容产线 | 自包含的 15 个 Skill：长文、图文、短帖、教程与资讯调研 | [Social Content Studio](social-content-studio/README.md) |

## 放置方式

- 小红书的文案、封面、配图归入小红书图文分类；产品调研和 PRD 等归入产品经理分类。实际作品仅在明确指定上传范围并核对公开权限后加入。
- 社交内容工作台按用户要求放在仓库一级目录 `social-content-studio/`，整包保留入口、共用能力、脚本、背景纹理和许可证。包内子技能不需要重复安装。
- 每套 Skill 保留独立的叶子文件夹、`SKILL.md` 和必要参考资源。已放入业务分类的 Skill 位于该分类的 `skills/` 子目录；跨业务工具放在根目录 `skills/tools/`。
- 每套交付包只在一个位置维护，用首页链接或标签表示用途。自包含工作台保留其包内依赖；原有独立 Skill 供单独使用，安装工作台时不需要同时安装重复的独立入口。得到大脑归为工具操作，不以“知识库”作为本仓库的总分类。
- 安装或调用时提供完整叶子目录，不只取 `SKILL.md`。仓库分类本身不会自动安装或启用全部 Skill，也不会修改本机全局 Skill 或其他 Agent 配置。

## 公开范围与维护

本仓库为公开仓库。仅发布核对过的通用 Skill、模板与分类说明；不上传账号配置、私人知识库、浏览器 Cookie、令牌、本机私有路径或临时媒体。后续新增文件仍需单独检查，不能把本次公开视为允许上传所有本地资料。

本次提交作者使用 GitHub 的 `noreply` 地址。它不是联系邮箱；仓库名、GitHub 用户名及提交记录仍会公开。

Social Content Studio 公开版已脱敏：不含私人目录、Notion 定位、项目原图和个案版本记录；使用者需自行配置保存位置与 Notion，并提供自己的参考图。原有单独小红书 Skill 的公开副本同样不含私人参考图路径。产品经理包保留原作者 zxh 与 MIT 许可，公开副本仅整理元数据兼容性。
