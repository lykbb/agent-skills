# 样例：深夜小面馆（滑杆）

2026-11 试跑记录。用 Levi 的通用提示词填入主题「深夜小面馆」后的完整产出，供新主题开工时参照。

## 输入（就这么多）

- 主题：深夜小面馆
- 形态：滑杆
- 特别要求：从备菜一路开到打烊；要有一只猫

## 五阶段剧情表（滑杆位置 = 时间）

| 位置 | 阶段 | 世界里发生什么 |
|---|---|---|
| 0–0.22 | 备菜 | 招牌没亮，师傅在案板前切菜（手臂上下动），炉火半温，锅上一点蒸汽，没有客人 |
| 0.22–0.5 | 开张 | 招牌亮起，师傅站到灶前颠勺，炉火最旺，第一位客人落座 |
| 0.5–0.82 | 夜宵高峰 | 三位客人到齐（低头吃面、碗上冒汽），师傅在吧台后递面；门口的猫出现，先睡着 |
| 0.82–0.93 | 渐渐打烊 | 客人一位一位离开（抖动溶解），师傅擦台，炉火转小 |
| 0.93–1 | 打烊 | 招牌熄灭，只剩灯笼和炉底余烬；师傅坐到吧台外侧吃自己的一碗面，猫睡在门阶上，高峰时段它会偶尔睁一下眼（发光的眼睛） |

其他随 L 联动的：月亮随夜色升起、街灯入夜亮起、水洼反光、灯笼随风轻晃、客人进出都用 Bayer 抖动溶解（和光档切换同一套语言）。

## 验收结果

- `npm run build`（tsc strict + vite）与 `npm run lint`（oxlint）均一次通过
- 静帧自查：把像素画师脱离浏览器单独跑，四个光档各导出一帧逐张看图核对——人物姿态、客人溶解进度、猫、余烬、招牌明暗全部符合上表
- 修过一处：画面两侧的地面原先悬空（远楼和街灯浮在半空），补齐地面后通过

## 踩过的两个坑（已写进 SKILL.md）

1. **交付形态**：第一版交付的是单文件 HTML 附件，用户在聊天 App 里打开只看到满屏源码——App 的文件预览不渲染网页。对策：交付优先给能直接打开就玩的形态（聊天内组件 / 单文件瘦身版），工程正本和交付副本分开。
2. **玻璃没法在助手侧亲验**：助手浏览器打不开本地页和托管副本（策略拦截），WebGL 合成效果无法自查。对策：验收清单里玻璃五项单列，验不到就在说明里明写未验，交给用户开页实测后回图再调数值。
