# glass-pill-world · 玻璃药丸小世界

一个 Agent Skill：一颗玻璃药丸里住着一个像素小世界，药丸本身是一个开关或滑杆，玻璃旋钮滑过之处，世界的光线和剧情跟着变。

改编自 [@Leviwoyun](https://x.com/Leviwoyun) 公开的玻璃药丸提示词（2026-11），并并入「深夜小面馆」试跑的全部实测经验（交付形态、静帧自查、玻璃验收）。

## 用法

装进你的技能目录（如 `~/.agents/skills/glass-pill-world/`），然后一句话开工：

> 用玻璃药丸做一个滑杆，主题是深夜理发店，从开门到打烊，要有一只猫。

你只需要给三样：**主题、形态（开关 / 滑杆）、特别要求**。技术栈、光档抖动、玻璃着色器、手感公式、无障碍、验收清单，全部写死在 [SKILL.md](SKILL.md) 里，不用每次粘长提示词。

## 里面有什么

- `SKILL.md` — 规格本体，给 AI 读的
- `examples/noodle-shop.md` — 第一个试跑样例：深夜小面馆滑杆的五阶段剧情表与验收记录

## 效果要点

- 176×50 的像素世界每帧由 CPU 现画，最近邻放大，永不平滑
- 四个光档之间用 4×4 Bayer 有序抖动切换，永不混合——这是这个风格的命门
- 玻璃旋钮是一个 WebGL2 着色器：1.28 倍放大、边缘色散、菲涅尔染色、双高光、投影，且透过透镜看世界永远是亮的
- 弹簧手感、拉伸与晃动、点按与拖动的分界、无障碍、`?demo=1` 自动演示、确定性静帧接口，一应俱全
