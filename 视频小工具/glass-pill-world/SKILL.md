# 玻璃药丸小世界

一个自成一体的 UI 控件：一颗玻璃药丸，里面是一个每帧重画的像素小世界。药丸居中放在一个满幅「房间」里，房间的颜色跟着控件走。旋钮是一块竖直的玻璃胶囊，滑过之处把像素世界放大、折射、染上色散。

## 开工只需要三样

向用户确认（缺了就问，不要自己编）：

1. **主题**：什么场景（如：深夜小面馆、理发店、猫的窗台、巨构脚下的小屋）
2. **形态**：开关（toggle，两端）还是滑杆（slider，连续）——主题里定了就按主题
3. **特别要求**：主角是谁、必须出现的东西、分几个阶段

其余一切按本文件的规格执行，不要再向用户罗列技术问题。

## 技术栈（写死，不替换）

- Vite + React 19 + TypeScript（strict）+ 纯 CSS。不加任何额外库：不用 three.js、不用 GSAP、不用图片、不用网络字体。
- 所有随机来自种子化伪随机函数，刷新后画面一致。
- React 只渲染一次：一个 effect 把引擎挂到 canvas 上，`requestAnimationFrame` 驱动，`dt = min(0.05, Δt)`，每帧不 setState。
- `dispose()` 必须取消动画帧、用一个 AbortController 摘掉所有监听、删掉 GL 对象。`<StrictMode>` 下双挂载要安全。

## 世界

- 像素缓冲尺寸：长滑杆约 176×50，开关约 144×76。每帧由 CPU 画进像素缓冲，最近邻采样放大，**永不平滑**；有空间时按整数倍设备像素放大。屏幕上的控件最大约 800×422 CSS px。
- 为主题原创一个场景。先列图层（后到前），每个物件都要「有工作」：随控件位置而变——居民醒来/干活/躲起来、灯亮起、天气变、两端各有一个小剧情点。
- 精灵用填充形状画，自动 1px 描边，上边亮、下边暗。
- 画布上的字只能是属于世界的小字形（如招牌），不承载信息；不要品牌、不要真人。

## 光

- 控件位置驱动光位 L。用四个光档（如白天 / 黄昏 / 暮色 / 夜晚，或按主题定），**每个材质在每个光档各有一个颜色**。
- 两档之间，每个像素用 4×4 Bayer 有序抖动二选一取色，**永不混合渐变**。这是本风格的命门，不许偷懒用 lerp 糊过去。
- 例外：房间颜色和玻璃边沿色可以平滑插值。
- 发光像素（灯、招牌、火焰、眼睛等）另进一张辉光缓冲，轻微模糊后在着色器里叠加。

## 玻璃旋钮

- 竖直玻璃胶囊，比轨道略高，在**一个 WebGL2 片段着色器**里覆盖整幅画布一次画成：
  - 放大约 1.28 倍，并把透镜下的像素弯折
  - 边缘红/绿/蓝分离，带一条暗折射带、一条亮边和菲涅尔染色
  - 两个高光：左上一条长而软的亮带，右下一个小亮点
  - 在世界里投一团柔和的影；**透镜内的景永远是全亮的**（单独备一份全亮档的世界缓冲供透镜采样）
- 没有 WebGL2 时退回 2D canvas：最近邻像素 + 一个简单玻璃环。退回也要能玩、能拖，不能黑屏。

## 运动与手感

- 弹簧跟随指针，拖动中更硬。松手时：开关带一点速度投掷（`x + v × ~0.18` 落点），滑杆停在松手处。
- 旋钮速度快时沿运动方向拉长、垂直方向等体积收窄；加速度喂给一个欠阻尼晃动，停下后还晃两下。
- 点按：开关点一下切到另一端；拖动超过约 4px 才算拖。滑杆点轨道 = 滑行寻位。
- 视差：图层随指针轻移，外加一个缓慢的待机漂移。
- `prefers-reduced-motion`：切换/寻位变瞬时，世界静止。暗色模式访客从「夜」端打开。

## 无障碍

- 开关：真正的 `<button role="switch">` + `aria-checked`，视觉隐藏的实时状态播报，方向键 / Home / End / Enter / Space 可用，焦点环可见。
- 滑杆：真正的 `role="slider"`（或视觉隐藏的原生 range），`aria-valuemin/max/now/valuetext` 实时更新，同一套按键。
- `touch-action: pan-y`，不能因为拖旋钮把页面滚走。

## 演示与确定性

- `?demo=1`：自动演示循环——一只画出来的指针点/拖这个控件，然后退场；真人第一次操作立即接管。
- 暴露 `window.__render(t)`：用固定 60fps 时钟步进一个全新引擎，同一个 t 永远出同一帧（自查和出图都靠它）。

## 交付形态（试跑踩过的坑，必守）

- **交付必须是能直接打开就玩的成品**，不要只丢一个源码文件：在聊天 App 里打开 HTML 附件只会显示源码文本。
- 优先顺序：聊天内可直接交互的组件/页面 > 单文件 HTML（可用时把 React 壳剥掉出一个瘦身单文件版，引擎同一份）> 完整工程目录。
- 工程本体保留 Vite+React 正本；瘦身版只是交付副本，不许反过来拿瘦身版当正本维护。

## 验收（Done when）

- [ ] `npm run build` 与 `npm run lint` 都过，控制台无错误，除页面自身文件外无网络请求
- [ ] 静帧自查：用 `__render` 或静帧钩子把每个光档各导一帧，逐帧看图核对——不是看代码：世界认得出、剧情点成立、没有黑块和悬空物件；至少过一遍「遮住标题当新观众看」的检查
- [ ] 玻璃亲验：透镜的放大、色散、高光、投影、透镜内全亮，五项逐项确认；验不到的环境要在说明里写明未验，不要默认它是对的
- [ ] 写 `out/说明.md`（中文）：概念、各部分做什么、检查过什么、已知问题
- [ ] 不 git commit、不 push、不发布，除非用户明确要求
