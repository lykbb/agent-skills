# 资讯·调研入口（05）

与 [01 深度长文](../01-长文-long-article/SKILL.md)、[04 教程](../04-教程-tutorial/SKILL.md) **平级**。文风对照见 [genre-defaults](../references/genre-defaults-01-04-05.md)。共享节点冲突时读 [冲突裁决](../references/design-article-ref-lessons.md#冲突裁决必读)；本入口默认**不得**推翻用户确认与 [pipeline](../references/pipeline-contract.md)。

沿用已确认题目与调研范围。未定题按 [总入口选题规则](../SKILL.md#选题先确认)。只改事实段或一张图时直接处理指定阶段。

## 调研顺序（硬规则）

开写正文前必须按序完成；跳步须用户当场授权并在交付注明：

1. **官网 / 官方博客 / 论文 / 发布页原文**（找不到官方源则标缺口，不拿二手自媒体当终审事实）。
2. **抽出可核事实**：名称、版本、发布/更新日期、地区与可用性、官方自称能力边界。
3. **对照已有技术判断**：真突破 / 仅新鲜感 / 常规资讯——写清对照对象与依据，禁止空喊「颠覆」。
4. **改变了什么**与**限度 / 尚不知**（未亲自测的不写效率数字；未核的标「尚不知」）。

近两年优质中文 AI/产品观察文可作后续范文池，不强制嵌入本 Skill。

## 本入口风格（与 01 明显不同）

- **目标**：读者在短时间内知道「是什么、核到了什么、值不值得跟进」。
- **结构**：是什么 → 可核事实 → 怎么试/对比（若有）→ 改变了什么 / 只是新鲜感 / 常规资讯 → 限度与尚不知。
- **语气**：用可核事实组织叙述，必要处交代归属与未知，不连续汇报核验过程。影响新闻定位或结论的日期、版本与地区条件保留；来源链接按 [14 来源交付](../14-正文写作-writing-skill/references/reality.md#来源怎样交付) 处理。
- **禁止**：空喊观点、假测评、未核效率数字、把教程步骤写成主线、套用 01 ~5000 字与深度反方发动机硬凑。
- **字数**：常 **2–4 千**；用户指定优先；材料不够就缩短，不硬凑深度长文。

## 配图与抓图默认

- **优先**：官图 / 发布图（注意版权与可否转载）、对比表、能力边界 / 关系简图。
- **少用**情绪大图、叙事插画、书桌套娃；修饰图最多点到为止。
- 每图 **存在理由**；截图与官图标明 **来源与日期**（计划或图注其一即可）。
- **抓图**：官网与可核验截图；过期界面标时间；禁假 UI 冒充产品图。

## 审纲之后与交付

正文稳定后默认 17→18；跳过须用户拍板。保存位置同总入口。正文不加行动号召与互动引导。读者面不写制作元信息。

范围与停点见 [pipeline-contract](../references/pipeline-contract.md)、[checkpoints](../references/checkpoints.md)。

## 中文包提炼（2026-10-24）

来源与分类见 [chinese-pack-lessons](../references/chinese-pack-lessons-2026-10-24.md)。强化调研顺序，不削弱「官网原文先行」硬规则。

- **官网/官方原文 → 对照突破**：先官方页/播客/发布说明，再与既有技术或竞品做**任务级**对照，最后才写真突破 / 仅新鲜感 / 常规资讯。
- **资讯 vs 调研深度差**：短讯可停在可核事实 + 一句「改变了什么」；调研须含试法或对照表，并单开 **界限**（明确不覆盖什么；忌「什么都想要」）。
- **日期与来源**：版本、地区、机型、语言可用性旁置发布/核验日期；个人实测写清时长与对象版本，不作排行榜。
- **配图**：对比表 + 真界面动线优先于情绪大图（本包 Circle / 工具实测类证据）。

## AI Skill 参考库增量（2026-10-24）

来源见 [ai-skill-ref-library lessons](../references/ai-skill-ref-library-2026-10-24-lessons.md)。强化事实边界，防串 01。

- **演示条件 vs 读者可复现**（实测段）：实测/配置结论同屏区分作者演示条件与读者可复现条件；标题带极端配置时，首屏拆穿代价与硬件前提。
- **人文个案资讯骨架**（非 01）：场景切入 → 可核事实/访谈细节 → 工具边界与代价 → **限度**；收束禁止鸡汤金句与时代升华（防串观点文）。

### 维护 / 实跑注意（2026-10-24）

- 执行时核：人文个案四段到**限度**；禁鸡汤收束；无实测也要声明演示/读者前提；大数字拆口径（例：「35 万」是 bots 数还是对话次数）。
- 规则变更走 [skill-maintenance](../references/skill-maintenance.md)；烟测见 [lessons](../references/ai-skill-ref-library-2026-10-24-lessons.md)。正式发稿全链路未压。
