# 短帖与推文串

用户已有明确选题或授权代选后起稿。未定题按 [总入口的选题规则](../SKILL.md#选题先确认) 默认查Notion选题库，推荐三至五个候选并等用户选择；“短帖直接交稿”不等于可以自行定题，不能从最近文件或模拟稿推定。用户明确题目或要求续做时不重复问，不做长文大纲或分页；需要长文或多页图文时交回总入口。仅加载当前短帖需要的包内规则。

## 最小流程

1. 识别用户指定的平台、单条或推文串、真实材料和观点。未指定平台时直接给通用短帖，不把篇幅写成某平台已验证限额。
2. 有动态事实或材料缺口时用 [13 调研核验](../13-调研核验-content-research/SKILL.md)；已有仍有效的依据继续沿用。仅凭用户的想法不能补成“亲测有效”。关键事实没核实，补查、删去该断言或向用户问清，不能把带“待核实”的内容包装成已可发布定稿。
3. 写一条主推荐。只有角度确实不同时才加一至两条备选；用户要求推文串时按条给出，每条推进一个点，第一条可独立理解。
4. 用 [14 writing-skill](../14-正文写作-writing-skill/SKILL.md) 的短内容与改稿模式复核本次文字。明确交接“纯文字短帖，不扩写成长文、不新增分页”；读取关联参考不重启其他产线。
5. 按 [19 发布复核](../19-发布复核-check-social-content-compliance/SKILL.md) 的适用项检查真实性、夸大、版权、隐私及商业披露。关键词命中结合品类和语境判断，不能用词表结果代替平台审核。
6. 按 [独立验收规则](../references/pipeline-contract.md#作者自查与独立验收) 让未参与起稿的Agent核对当前完整文字、原始材料、条件和口吻。只处理具体问题，不扩写、不分页；无法独立调用时如实标注自查范围，不假称通过。
7. 直接交稿。X 短帖在对话里直接给出正文和配图，不在 Mac 本地保存文件（用户随发随用，不留本地记录，用户确认 2026-10-27）；其他平台短帖按总入口保存 Markdown 到当前内容项目。用户接着改哪一句，就只改相应范围；不以“再确认一次定稿”为默认前置门槛。

涉及 X、微博、即刻、朋友圈时，19 只提供适用的通用复核；其小红书、抖音、both 参数不代表这些平台已覆盖。只有要判断发布限额或实时平台规则时才核对该平台当前官方依据。

## 写法与平台适配

第一句给核心信息或判断，随后给一个必要理由、细节或条件。自然口语，像本人向熟人说清一件事；不强塞俚语、粗口、口头禅。不加引导观众的话语：不写行动号召、互动引导或求赞话术，不向读者布置任务或以发问收尾，结尾停在内容本身；规则正本见 [阶段分工](../references/pipeline-contract.md)。

单条通常只讲一个点；推文串各条有新增信息，不重复首条。转自长文时沿用原稿观点、事实与来源，不修改原长文。个人经历或观点没有公开来源时不编链接；使用公开事实、引用或产品信息时附实际读取且重要的来源。

平台未指定不反复追问。小红书纯文字帖需要标题时，按 [16 标题规则](../16-标题封面字-title-creator/SKILL.md) 选适用写法，给少量候选即可；朋友圈、即刻等不强制另起标题。标签和语气服从用户要求，默认不堆标签；表情按下一段的少量用法。

X 短帖（含推文串各条）排版紧凑：段与段之间不空行，一段一个换行，整条连着排（用户确认 2026-10-27，不要有那么多空行）。短帖可以少量加表情（用户确认 2026-10-27，稍微加点表情）：一条通常几个，落在自然的段落节点，不每句都加，不替代词语，也不堆在结尾。

需要声称字数符合某平台限制时，按该平台当前规则及实际计数口径验证。普通字符数不能冒充 X 加权字符数；没有适用计数工具时说明未验证，保留篇幅余量，不编“已通过”的结果。

## 可选单图

默认纯文字。用户已要求配一张图时，按已授权范围交给 [18 图片工作台](../18-生图制作-social-image-studio/SKILL.md)；只是 Agent 认为配图更好时，先提建议，获得授权再做。只做单张辅助图，交清主张、完整文字、尺寸、素材、基准和来源，不进入 15 分页。单图若是流程图或架构图，用 `diagram-design` 设计，不走通用生图（用户确认 2026-10-27，见 17）。

实际配图在基础检查和独立成图验收后交付。没有视觉基准时按 [确认节点](../references/checkpoints.md) 让用户看首张；已有基准或已明确指定方案时沿用。文字交付和可选图片分别说明完成状态，不因暂未配图卡住短帖。

## 边界与完成

短帖完成应有一个清楚的点，材料能支持其中事实，保留必要限定，完成自然表达与适用风险复核，并按用户要求交付。需要保存时附真实保存位置；仅对话交付不要求落盘。检查记录可以留在对话，不另存过程报告。

不自动登录、发布、回写 Notion、上传私人稿件、付费或安装。未定题时按前述规则只读查库推荐；只有用户明确要求入库、补充条目或改状态时，才按 [Notion 适配](../references/notion-topic-library.md) 执行写入。细节见 [阶段分工](../references/pipeline-contract.md)。
