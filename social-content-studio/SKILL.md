# 社交内容总入口

## 维护（非写作）

用户提到**维护、改 Skill、完善优化、入库规则**且当前不是在写具体文章时：先读 [维护注意事项](references/skill-maintenance.md)，再改文件。写文章走下方文体入口，不把本清单当写作流程。


先识别本次是在创作内容、维护技能还是演练流程。维护和演练不自动变成真实内容生产。创作时再识别文体、用户选定的题目、已有确认和本次交付范围，选择**一个**入口；不要求用户手动挑文件，不一次加载全包。文风对照见 [01/04/05 默认](references/genre-defaults-01-04-05.md)。

| 文体 | 包内入口 | 主要产物 |
|---|---|---|
| 深度观点长文 | [long-article](01-长文-long-article/SKILL.md) | 大纲、正文及封面、插图与流程图 |
| 小红书静态图文 | [xiaohongshu-post](02-图文-xiaohongshu-post/SKILL.md) | 分页、逐页文字、发布文案、封面与内容页 |
| 短帖与推文串 | [short-posts](03-短帖-short-posts/SKILL.md) | 一条短帖或按条组织的推文串，配图按要求另做 |
| 教程 | [tutorial-article](04-教程-tutorial/SKILL.md) | 步骤大纲、可照做正文、说明图为主的配图 |
| 资讯·调研 | [news-research-brief](05-资讯调研-news-brief/SKILL.md) | 事实→验证→限度短文、官图/对比/边界图 |

## 文体分流（精准进门）

1. **用户点名或触发词** → 直接进对应入口：  
   - 教程 / 步骤 / 怎么装 / 怎么用 / 上手 / 操作流程 → **04**  
   - 新品 / 发布 / 怎么样 / 测评 / 调研 / 速览 / 对比 → **05**  
   - 观点 / 边界 / 取舍 / 「还剩下什么」类深度题 → **01**  
   - 小红书图文 / 短帖 → **02 / 03**（不变）
2. **未点名时看材料**：有可复现步骤清单 → 偏 **04**；有发布日 + 待核事实清单 → 偏 **05**；主要是立场 / 取舍 / 边界论证 → **01**。
3. **拿不准只问一句文体**，不并行开 01/04/05 三条。
4. **文风不得串味**：01 勿写成说明书；04 勿升华成行业评论；05 勿空喊观点或假测评。对照表见 [genre-defaults](references/genre-defaults-01-04-05.md)。

## 选题先确认

“已定题”指用户在当前任务中明确指定或选定题目、要求基于指定原稿创作，或明确要求续做一个已确认的任务。仅调用本技能、发现相关稿件、文件最近修改、历史做过或存在模拟稿，都不构成选题确认；不能据此扫描旧项目后自行开题。

创作请求没有已定题时，默认按 [Notion 选题库适配](references/notion-topic-library.md) 读取选题库，推荐三至五个确实不同的候选，给选择理由并等待用户选择，不再先问是否查库。用户明确要求找热点时，可先用13探索，结果仍是待选候选。用户明确授权代选时可在其范围内代选，并保留后续默认确认点。库不可访问或没有适合条目时说明具体缺口，请用户给题目或条目，不以最近本地文件替代选择。

用户已定题直接进入对应入口，不重复问选题，不为已有材料另找题目。未指定文体且上下文无法判断时，只问最影响下一步的选择，不同时开三条线。

## 调度与确认

五个入口按 [阶段分工与验收](references/pipeline-contract.md) 使用共用能力；01/04/05 默认对照见 [genre-defaults](references/genre-defaults-01-04-05.md)。长文相关增量原则见 [设计文章参考教训](references/design-article-ref-lessons.md)（含冲突裁决）；AI Skill 参考库增量见 [ai-skill-ref-library lessons](references/ai-skill-ref-library-2026-10-24-lessons.md)；与 pipeline / 用户确认冲突时以上者与用户确认为准。文件夹编号用于浏览，各文体按依赖关系选节点。始终从当前 SKILL.md 所在目录解析相对路径。

同一个旧技能可能包含完整流程。本入口调用它时，明确当前阶段及输入、输出：读取其中的参考不等于再次启动入口。用户已确认的事实、文案、页序和风格继续沿用，后续节点只处理自己的任务。

题目确定后：01/04/05 均在补全大纲后审纲，正文稳定后默认走17→18（配图默认按入口不同，见 genre-defaults）；小红书依次审内容大纲、完整文案、正式分页（大纲附 2-3 个视觉方向供选定；总张数≤8 时大纲附页分配，合并审大纲与审分页），文案确认后才正式分页，分页确认后硬性走15规格→18（不经17）。需要建立新视觉基准时，首张图出来后等用户定风格。跳过配图/出图须用户当场拍板。短帖在题目明确后直接交纯文字稿，单图按要求直连18。具体停点、授权与返修按 [确认节点](references/checkpoints.md)，用户明确指定的停点和连续推进范围优先。

所有正文、标题、封面和图内文字，在交付或制作前按14 writing-skill做自然表达与内容保护复核，保留作者原意、重点、限定和已确认结构。事实、用户自述、观点、教学示例与待验证方案分开。

所有文体读者面不加行动号召与互动引导；结尾停在内容本身。正本与示例见 [阶段分工与验收](references/pipeline-contract.md)。

封面与内容页的文字性说明元素、视觉点缀及稀疏封面的小标签例外，统一按 [阶段分工与验收](references/pipeline-contract.md#文字计划与图片分别验收) 执行；轻量补充的适用条件见 [18 系列改稿](18-生图制作-social-image-studio/references/series-and-revisions.md#稀疏封面的轻量补充)。

每个阶段由作者做必要自查；完整文字和实际成图在交审或交付前，按 [独立验收规则](references/pipeline-contract.md#作者自查与独立验收) 交给不同审阅上下文的Agent验收，不在每个步骤另开Agent打分。独立验收不能由作者自查冒充，也不能替代用户确认；已有同版检查按影响范围复用。

## 保存与交付

01 长文与 04 教程按下列 Notion 优先规则交付；其他文体沿用各入口的保存约定。交付时在对话给出实际 Notion 页面链接或本地绝对路径及用户指定的内容。创建或修改前核对已有内容，不静默覆盖认可稿；未获用户改选，不用候选版本替换认可版。

- **01 长文与 04 教程默认交付到 Notion**：使用者配置的成稿归档位置中对应周页面的开头，正文与实际配图一起放好，图片按段落插入，不能只留本地路径或占位。按用户时区与交付日期定位对应周，用户指定周优先；先读取周页面，保留原有内容，核对同稿避免重复归档。写入后回读检查正文、图片及顺序，不能把本地成稿称为已写入 Notion。
- **只有当前 AI 无法使用 Notion 时才改为本地交付**：例如没有可用连接、访问权限不足或连接失败。说明具体限制，将 Markdown 正文与配图保存在既有本地题目项目；本机默认正文根目录为 使用者本地配置的正文根目录，按 17 处理图片引用并检查实际显示。不能因习惯本地流程就跳过可用的 Notion；能连接但未定位周页面时先查找或澄清位置。
- 必要的图片制作工作文件、可编辑源，以及小红书图文和短帖（X 短帖除外，见 03：对话直接交付，不落盘），仍沿用 使用者本地配置的视觉项目根目录 下对应日期与题目项目。制作时使用本地工作文件，不等于已完成 01/04 的 Notion 交付。
- 长文文字与图片分开存放时，按 [17 的保存、嵌图与交付规则](17-长文配图-article-visuals/SKILL.md#制作检查与交付) 处理；图号与制作对应关系可留内部索引，读者面图注按实际理解需要决定。验证实际阅读结果，不以「已嵌图」名义只留路径或索引。
- 用户本次明确指定的交付位置优先；已有项目目录只决定制作文件和本地兜底位置，不改变 01/04 的默认 Notion 归档。迁移到其他机器后先确认新的保存根目录，不创建旧用户名路径。用户只要对话稿时按其要求交付。

切换节点只交接当前所需 [信息](references/handoff.md)，一般信息直接留在对话或正式稿件中。用户明确认可的版本按 [认可稿记录](references/checkpoints.md#认可稿记录) 登记到对应内容项目的项目说明；续做先读取该记录并核对实际文件。认可记录是持续维护的版本映射，不另建状态回执和过程报告。

本产线只处理静态内容；旧工作台中的视频、音频与实况照片分支不在本次范围。01/04 的 Notion 成稿归档按上述用户约定执行；其他 Notion 回写、上传私稿及安装、付费、公开发布仍须另有用户授权。缺少工具时交付可完成部分并说明具体缺口；文件检查、文字扫描和实际成图分别说明，不把前两者称为整条产线跑通。
