# 制作与审查

十个环节按 SKILL.md 的顺序检查，已有确认沿用，条件分支不适用时不调用；不得把保留完整机制理解为每张静态图都要制作地图或视频。

## 范围与内容审查

检查当前页、总张数、平台、画布、用户原文和整组风格基准。既有内容可直接进入制作，不重新启动选题。总览、解释、截图与结尾各有职责；图文正文可以总结，组件图按要求列全。对照原材料核对名称、数量、例子、上下游关系和技术限定。

图内文字交付前按既有 writing-skill 做自然表达和内容保护复核；不为了口语或整齐删掉必要限定。用户明确给定标题，就按其主题、数量和命名排版，不另造钩子。涉及发布风险，按既有 check-social-content-compliance 检查适用的标题、可见文字、图片、授权和隐私；涉及最新规则或高风险结论时再查证。外部检测平台需登录、耗费篇数或上传私人内容时，不擅自进行。

## 模板、背景与素材审查

必须检查本页选用了哪个完整视觉系统、配方及主题；按 components 和 portrait-fill 核对字体、卡片互斥、标题长度、竖版空间和手机阅读。用户明确的加粗、分隔、尺寸与标题优先于默认设计参数。

读取 qa-checklist 的所有适用项：文字、布局、风格身份、图像、图上文字、四横带密度和交付。密度不足先选适合内容的配方、调整真实内容和留白；不造日期、来源或数字。

截图按 [截图处理](screenshot-treatment.md#comparison-subjects-not-just-equal-containers) 检查真实素材尺寸、窗口主体清理、原比例和实际裁切，多图以可见主体对齐而非只对齐外容器；照片检查主体图、脸和手的避让、亮度静区、局部蒙层必要性与360px缩略图。地图核对真实底图和示意关系，跨平台核对独立构图和短标题。Swiss核对单一强调色与平面排版；Editorial核对纸底、颗粒、背景氛围、内容分层和背景资源就绪。

流程与结构图还须核对箭头实际连接的语义节点，不能与辅助线或分隔线相接、相交而产生歧义；检查导出后的遮挡、上下视觉重量和实际留白。源文件写了居中、间距相同或脚本/其他 Agent 给出通过，均不能代替实际几何与图意检查。沿用现有排版底线，不把本次像素值固定给所有图。

### 产品介绍封面的专项审查

- 以 360px 宽缩略图检查：不看正文，也能从主视觉辨认完整产品名、对应 Logo 与中文用途，不能只剩一个醒目的泛化标题。
- 检查名称、主标题和 Logo 的组合关系，以及左右视觉重量；产品名不孤立成横幅，Logo 不因内部留白而看起来过小，也不挤压标题或越界。
- 检查图内表达是否具体、自然，副标题是否提供新信息；使用用户当前认可的配色，不机械回到蓝色默认。Logo 或文字的局部修改完成后只复查受影响部分。
- 对照官方口径核对产品标识与使用限制；安全和隐私表述保留具体适用流程，不能把审批或防护机制写成保证不会出错。

## 渲染与自动检查

1. 核对使用的HTML、图片、字体、图标、纹理和背景脚本；图片载入失败、占位素材未替换或字体与预期不符，不能只凭页面能打开就交付。
2. 运行 render-social-card 的 check-only 或等价页面检查：唯一目标节点、可见边界、文字溢出、元素裁切及真实画布像素。
3. HTML画布运行 validate-social-deck：保留R1溢出、R2页脚碰撞、R3字重、R4字号、R5密度、R6标题容量、R7figure偏移、R8可见边界、R9标题间距全部规则。零画布、运行失败和缺依赖不等于通过。
4. 处理真正阻塞阅读和缺失内容的问题；风格或密度WARN结合用户已确认的设计判断。若用户明确选择与模板默认不同的字重等，只记录相应例外，不谎称该规则自动通过。不能为了消除告警破坏原文、隐去限定或加入假数据。
5. 导出并目检实际PNG与手机缩略图，确认文字、图标、素材及相对位置。修复后只复查受影响项目；已通过且未改动的部分不重复运行。

溢出修正沿用阶梯：1–40px局部移动或间距；40–90px局部紧凑；90–160px适度调标题或段落；更大时才考虑换配方或经授权调整内容。修完还要确认没有变成大块无理由留白。

## 实况额外审查

保留 live-photo-production 的完整流程：探测源视频 → 稀疏联系表 → 判定裁切与信息预算 → 首帧静态预览确认 → MOV和关键JPG → 相同标识符元数据 → PVT打包 → 时长、帧数、裁切、包内容和联系表检查 → iPhone路径与实际验证状态。

确认单视频、二/三/四宫格或长视频走法，不擅自延长短素材、不把假定格序列说成真实视频。脚本可运行不代表手机可识别，未做设备测试时明确未测。GIF/MP4降级须按用户选择，静态图片不进入该分支。

## 反馈与成稿

单页换风格只是例外，下一张继续整组基准；用户明确要求整组改风格时再更新基准。每轮只交指定图片，整组完成再核对页数与组件覆盖。不输出检查回执文件；在对话中简述实际检查范围与未验证项。已交付旧版本按用户确认规则处理。
