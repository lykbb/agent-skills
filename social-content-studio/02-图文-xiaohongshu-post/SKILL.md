# 小红书图文入口

先判断本次是整组、内容大纲、文案、分页、封面、内容页还是局部修改。未定题按 [总入口的选题规则](../SKILL.md#选题先确认) 默认查Notion选题库，给三至五个候选并等用户选择；不能把最近文件、相关旧稿或模拟稿当成本次已定题。明确要求续做或基于指定原稿创作时不重复选题。

用户已认可的大纲、文案、页数、页序和系列基准继续沿用，只补当前缺失或要求修改的阶段。用户指定单页且已有充分确认信息时直接从该页进入，不重开审纲、审文案或审分页。纯文字短帖进入 [03](../03-短帖-short-posts/SKILL.md)。

内容由15组织，14保护表达与含义，18实现画面。**未定来源不写主张**；类型→来源优先级与点子对齐见 [15 source-first](../15-小红书分页-xiaohongshu-image-posts/references/source-first.md)。本入口采用“内容大纲→完整文案→正式分页”的顺序；旧15中的“分页框架→文案”不作为本入口的执行顺序。读取旧技能的方法和参考时，只执行本表当前职责，不再次启动其中的完整产线。

## 分阶段推进

| 节点 | 任务与调用 | 输出及停点 |
|---|---|---|
| 可选取题、11 | [选题库](../references/notion-topic-library.md) 或 [转写整理](../11-转写整理-clean-long-transcript/SKILL.md) | 无题先推荐并等用户选；题目明确、无转写时跳过 |
| 13 | [调研核验](../13-调研核验-content-research/SKILL.md) | 只补会影响主张的事实、来源及限制；方法提案不编效果数据；小红书来源优先级见 [15 source-first](../15-小红书分页-xiaohongshu-image-posts/references/source-first.md) |
| 15A：内容大纲 | 取 [15](../15-小红书分页-xiaohongshu-image-posts/SKILL.md) 的主题与内容组织方法，先不正式分P1/P2 | 核心问题、主张、内容顺序、材料与边界、建议张数及容量；附 2-3 个确实不同的视觉方向供选定——各方向覆盖不同强调色与版式配方，从 18 的四色板、28 配方与背景系统按内容气质提案，不以默认或上一篇配色顶替；总张数≤8 时同时附页分配；交用户审大纲 |
| 15B：完整文案 | 在已认可的大纲内写齐主文案，以用户原话为素材、可总结提炼，按逻辑段落组织，另写发布正文 | 面向图文容量的完整文字，口吻与重点经14人味自查；不扩成长文，不先交正式分页 |
| 16：标题与封面字 | [标题与封面字](../16-标题封面字-title-creator/SKILL.md) | 区分发布标题、封面大字和必要小标题，围绕同一主张；封面字先按 15「类型→封面」对号——产品/工具介绍封面必带完整产品名、官 Logo 与一句话用途（见 [cover-by-genre](../15-小红书分页-xiaohongshu-image-posts/references/cover-by-genre.md)），产品名与 Logo 显著放大进主视觉、可居中作封面主角，不限于左上刊头，照片相应收窄让位。动笔前实际读取 16 SKILL.md，发布标题与封面大字候选逐个过换名测试（换名仍成立即品类共性，毙），留痕同 14 口径。可兑现上允许有限抓眼（见 16）；封面大字只押一个信息点；小红书可适度 emoji（见 15），长文不加 |
| 14：文字复核 | [人味复核](../14-正文写作-writing-skill/SKILL.md)，仅当前全部文字 | 自然表达且保留事实、限定和结构的主文案、标题、封面字及发布正文 |
| 独立文字验收 | 按 [独立验收规则](../references/pipeline-contract.md#作者自查与独立验收)，给另一审阅上下文当前文字与依据 | 核对事实、限定、逻辑、表达、标题兑现与封面字题型合规（见 16 行），处理具体问题后交用户审文案 |
| 审文案 | 一起交完整文案、标题、封面字和发布正文 | 等用户确认后才进入正式分页，不把审大纲当成审文案 |
| 15C：正式分页 | 将已认可的主文案按15的方法分配到各页，复核发生变化的文字 | 总张数含封面、每页职责、页型（文字页/图示页）、完整图内文字、必要素材与关系类型；分层/对比/流程优先图示；交用户审分页 |
| 18：图片制作 | [图片工作台](../18-生图制作-social-image-studio/SKILL.md)，接收已确认的分页与制作规格 | 先做授权首张及基础自查，经独立验收、用户定风格后继续已授权页面 |
| 19：发布复核 | [发布复核](../19-发布复核-check-social-content-compliance/SKILL.md) 与工作台视觉检查 | 提供适用检查结果供独立验收复用，不把同版扫描重复当新证据 |
| 独立成图验收 | 读取实际图片、认可文案及规格，核对文字、关系、手机可读性和系列一致性 | 首张交用户定风格及最终本次成图交付前验收；未变部分复用，不每张重审全组 |

大纲决定讲什么及内容顺序；文案决定具体怎么表达；分页决定每张承担什么、放哪段文字和配什么图。用户指定张数时，从大纲和起稿阶段就按该容量控制内容；未指定时给建议张数，正式分页时确认总数。不能写完一篇超量长文后硬切成卡片。

主文案与图内文字不加行动号召与互动引导；旧15互动/结尾建议不适用。正本见 [阶段分工](../references/pipeline-contract.md)。

总张数≤8 时，大纲直接附页分配，一次审过即视为审大纲与审分页同时通过，中间保留审文案；用户要求分开审或张数更大时按三停点。审大纲、审文案、审分页是不同确认。每次交出当前完整产物后等待，不提前执行依赖该决定的下一阶段。审文案通过后可正式分页，审分页通过后才进入已授权制作；用户本次明确合并或跳过某停点时遵从其范围。只要文案不自动解锁图片制作。

已有确认稿直接沿用。已有分页、尚未确认文案时，保留认可的张数与页序，补齐并审文案；仅核对受影响的分页，不推倒重来。小红书选题和内容由15负责，通常不进入12长文大纲或17长文配图。

## 分页时保护确认稿

按已认可文案分配内容，可去重复、调整断句和页内表达；保留观点、依据、重要限定及上下文联系。新增页标题、图注或改动文字在交审分页前，按14复核相应部分；若影响已验收含义、事实或重要条件，只补独立验收受影响项，不重审未变文案。若需要删除重要内容、改变含义或偏离已认可主张，说明具体位置及影响，返回文案确认；改变已确认总张数或页序时返回分页确认。不为装下文字自行删条件、改事实或扩页。

## 锁定本组规格

首次交接18前说明以下内容，可以直接放在当前对话或正式稿里，不另建回执：

- 平台、总张数及本次授权页面；总张数包含封面，旧参考中的推荐页数不扩张已确认范围。
- 已认可大纲、文案与分页的对应关系；每页职责、完整图内文字和必要素材。发布正文单独交付，不原样塞进图里。
- 尺寸与视觉基准：新系列默认1080×1440、3:4；已有系列优先沿用认可成图的实际尺寸、配色、字形和边距。其他旧节点的默认尺寸在本次制作中服从这一规格。基准只锁定设计 token（色板、字栈、字号阶梯、边距、画布），不锁定构图骨架：构图按内容重新提案、优先选 18 配方，页型分文字页/图示页/纯文字页（无结构不硬套框架），遵守网格、垂直画布分配、层级、字号阶梯、孤字不成行与出图前平衡校验等排版底线，详见 [阶段分工](../references/pipeline-contract.md)。
- 素材角色：真实截图、原图、风格参考、生成示意分开；需要来源或状态标注时一并交接。
- 小红书正文与图内字**一律不写**具体价格/额度数字（写死也不行）；禁止「以官网为准」。详见 15「价格与额度」。分页/封面前若需真界面、官 Logo 或官仓示意图，**先联网取证**，类型→封面与抽象规则见 [15](../15-小红书分页-xiaohongshu-image-posts/SKILL.md) / [cover-by-genre](../15-小红书分页-xiaohongshu-image-posts/references/cover-by-genre.md)。
- 拉丁/英文大字字距与官网图审美：见 [18 拉丁字母字距](../18-生图制作-social-image-studio/SKILL.md#拉丁字母字距成图硬闸用户已确认) / [18 官方素材可弃](../18-生图制作-social-image-studio/SKILL.md#官方素材可弃审美用户已确认)；**未要求就不加图**，取真≠必贴官例；禁「官方生成示例」角标/图下解说上图。
- 首张若字多乱排（见 [反面 CASE](../references/visual-cases/xhs-first-gen-clutter/CASE.md)）→ 不定风格，重出后再交审。
- 哪一张用于定风格、是否已有基准、已经做完哪一页和下一页是哪一页。

未选风格时，18根据内容提出一套主推荐与必要备选；按当前用户偏好选择，保留系列一致性。方法题不强套产品新闻标题、产品Logo或“独有卖点”；标题从真实主张提炼，不编亲测、新闻或效果。

18负责容量、版式、字体、裁切及实现。装不下时先调整布局；需要改变确认稿、删重要内容或增加页数时，交回内容节点并按确认范围处理。不为通过风格检查添加假来源、假数字或无意义标签。


## 出图硬性默认

审分页通过后，必须进入 18 按已锁定规格生图（新系列默认1080×1440、3:4），不经过 17。15 负责分页与图内文字/模板意向，18 负责成图。只有用户当场明确说「只要文案/分页、不要出图」时才可跳过 18，并在交付时写明；Agent 不得自行省略。局部改一页文字且用户未要求重出图时，可只交付文字，但须标明图片未更新。

出图后对背景氛围层做像素复测：纸底应保留基色暖度与纹理方差；若背景区呈中性灰（R=G=B）且方差趋零，判氛围层失效返修。18 的 WebGL 墨流背景在无头渲染环境可能整幅渲成纯白画布、把暖纸色洗成中性灰（2026-10-24 实测），失效时改用 18 background-systems 的 2D 回退（纯 CSS 纸纹点阵、墨晕与等高线），并复测通过后再交验收。

## 改稿与完成

“下一张”根据既定页序、最后交付页和系列基准确定；信息不清只问缺的页码或基准。某一页的局部风格例外不自动升级成整组基准。未授权整组时不批量出图；已授权且确认点通过时不逐页重复索要同一授权。

生图前检查本次文字，出图后核对实际图片、文字、关系、手机可读性与实际像素。关键词命中要结合品类和完整语境判断，如“一段文字”不能因命中奶粉分段词表就机械删改。扫描与目检各报告实际完成范围。

最终文案与逐页文字存Markdown，成图及可编辑源放当前内容项目。只要策划或文字时交对应成果；图片未生成不能标为“整组完成”。边界和检查复用见 [阶段分工](../references/pipeline-contract.md)，停点见 [确认节点](../references/checkpoints.md)。
