# 手绘草图流程图（可选风格说明）

**何时读**：17 规划流程/结构/分工关系说明图；15 小红书分页需要流程图页；18 生图提示要白板/Excalidraw 感时。按当前任务需要及使用者确认选择，不视为统一默认。

## 正例

公开版不附原参考图；以下仅描述视觉特征，制作前仍需查看使用者实际提供的参考。

可选视觉方向：白底、略不规则手绘线、圆角框、手写感中文、柔和粉彩色块、左→右流程 + 可选底栏并列角色；信息密度中等、少装饰噪音。

## 风格配方（生图对齐）

| 要 | 不要 |
|---|---|
| 略抖动手绘描边、圆角框、菱形决策、箭头短标签 | PPT 立体卡片、厚阴影、渐变塑料感 |
| 白底干净；浅蓝/浅绿/浅粉/浅黄等柔和填充 | 摄影写实、潮玩 3D、满屏代码墙 |
| 中文手写感可读；节点少、主路径清晰 | 密 UML/状态机教材扫描；伪字乱码 |
| 流程/体系/分工关系绑文章步骤或论点 | 无关氛围草图充数；假 UI 冒充产品原图 |

**提示关键词（可各取一行）**  
中：手绘白板流程图，Excalidraw 感，略不规则墨线，圆角色块，粉彩填充，白底，中文手写标签，左到右流程，少装饰  
英：hand-drawn whiteboard flowchart, Excalidraw style, slightly wobbly ink lines, rounded pastel boxes, clean white background, handwritten Chinese labels, left-to-right flow, medium density

## 何时用 / 不用

- **优先可用**：涉及流程图、体系结构、角色分工、决策分支、工具链顺序——说明图任务明确时，按此风格生成（长文与小红书皆可）。
- **不用**：写实场景、产品真截图、封面少字主视觉、情绪修饰图等仍走原图种/风格菜单；**不是**全站配图都改成草图。
- **绑图**：01 说明图尽量绑论点；04/05 **必须**绑文章步骤/产品/证据（见风格表绑图松紧）。有文件≠能解释正文——反例见 [agent-homogeneity](../agent-homogeneity/CASE.md) 关于流程图语义与几何的说明。

## 比例（硬口径）

| 入口 | 画幅 | 说明 |
|---|---|---|
| 公众号长文插图（17） | **横构图**为主，宽幅适配正文；制作宽建议 ≥1080px | 可左→右展开；勿默认竖卡 |
| 小红书分页（15→18） | **竖版 3:4**，默认 **1080×1440**（与 02/pipeline 一致） | **竖版重排**阅读顺序；禁止把长文横图硬缩成小字 |

同内容跨平台时：长文可交横版源；小红书必须按竖版重画/重排，不直接贴横图。

## 与风格标签

本风格对应风格表 **L 手绘草图流程**（可用说明图风格，**不是**禁用的 H/I/J/K）。图种层仍属「流程/步骤图」或「关系/结构图」；先图种再套 L。

## 迁移边界

只学线稿手感、粉彩、流程信息结构与比例分工；不锁某一产品文案、不固定底栏五个角色、不升为封面默认或全篇唯一图种。单次认可可多画，不视为已替代表格/真截图等其他说明手段。
