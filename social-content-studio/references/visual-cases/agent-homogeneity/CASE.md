# 相似性、视觉隐喻与截图对齐：匿名文字案例

适用于 17 选择表达、18 构图和成图复核。公开版已脱敏，不附私人封面、用户反馈履历、文章原句、版本身份或第三方界面截图；以下只保留可迁移方法，不作为新任务的已认可视觉基准。

## 相似关系先变成可辨认的对象

要表达多种产品的共性，可以用共同轮廓与不同细节，让对象和关系都可识别。角色、物件、数量、媒介、色板和构图随题重选；不得把外形相近推成代码同源、性能相同或抄袭。

真实教程、新闻或比较证据需要实际材料，不能用拟人插画替代截图或事实。

## 通用隐喻可能抢走主题

建筑、道路或门等隐喻若可无差别套用多个无关主题，就可能不足以承担本篇主视觉。先请审阅者只看图与封面字，说明讨论对象与关系，再对照正文。某个组合失效不等于禁止该媒介或问句。

## 换字体不能修复主题脱节

先检查对象与主张，再处理字重、字号、断行和配色。不要把一次返修中的字体或像素参数升为所有图片的统一规范。

## 流程图的语义与几何都要检查

连线连接语义节点，避免与装饰线产生误读；并列职责可用对照，存在先后或依赖才用箭头。检查实际文字、分区、对齐、留白和手机端可读性。作者自查与独立复核均不能替代用户确认。

## 截图对齐要量主体，不能只量容器

两张截图的容器等宽时，窗口主体仍可能因透明阴影和额外留白而不同。先测量真实主体边界，去除窗口外的装饰空间，再统一外部标签和间距；保持窗口原比例，不重绘真实 UI 或裁掉产品内容来硬凑同高。

具体方法见 [截图处理](../../../18-生图制作-social-image-studio/references/screenshot-treatment.md#comparison-subjects-not-just-equal-containers)。

## 文字修订保留事实条件

合并重复声明与同义结尾时，保护日期、比较条件、假设和作者判断。尤其不能把带有“如果”的假设句改成已经发生的事实。删制作说明与删必要限定是两件事，见 [改稿规则](../../../14-正文写作-writing-skill/references/revision.md)。

## 使用边界

只借当前题目需要的方法，不固定角色数量、配色、字体或版式，不新增停点或额外报告。确认节点沿用原流程；选型见 [视觉风格表](../../wechat-visual-style-menu.md)。

文字保护见 [14 writing-skill](../../../14-正文写作-writing-skill/SKILL.md)，图种规划见 [17 article-visuals](../../../17-长文配图-article-visuals/SKILL.md)，制作检查见 [18 social-image-studio](../../../18-生图制作-social-image-studio/SKILL.md)。
