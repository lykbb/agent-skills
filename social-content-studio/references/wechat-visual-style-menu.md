# 公众号长文 · 视觉风格选用表（内部）

来源观察：`使用者提供的中文参考图库`（风格极杂）。  
用途：给 **17 配图计划** 说清楚「这张图干什么、用哪类风格」；**不是**鼓励同篇堆满所有风格。  
冲突时仍按 [冲突裁决](design-article-ref-lessons.md#冲突裁决必读) 与用户已确认的写实混搭默认。

## 先定用途，再选风格

规划每张图时必须先填两格：

1. **用途**：`封面` / `说明图`（讲清步骤·关系·对比·证据） / `修饰图`（情绪·章节停顿·阅读休息）
2. **存在理由**：文字难说清，或需要休息；无理由不加图

然后才从表里选**一种**风格。禁止「先挑好看风格再硬塞进段落」。

## 风格标签（从参考包归纳）

| 标签 | 长什么样 | 公众号 01 深度文 | 04 教程 | 05 资讯·调研 |
|---|---|---|---|---|
| A 氛围摄影/空间留白 | 真实光影、空景、画廊墙、窗边城市 | **封面优选**；正文开篇情境可用 | 少用 | 封面可用 |
| B 真人实景/过肩工作 | 人在场、浅景深、生活点缀；禁暗代码墙 | **正文修饰/开篇优选** | 可选 0–1 张带入 | 少用 |
| C 强标题设计封面 | 大色底+少字+一个道具/门洞剪影等 | 封面可选（压字要稳） | 封面可用 | 封面可用 |
| D 说明信息图 | 对比表、分栏、少节点流程、干净导出 | **说明图主选** | **主选** | **主选**（对比/边界） |
| E 真界面/官网截图 | 产品 UI、发布页、文档；可轻拼贴 | 有证据时用；不造假 UI | **主选** | 官图/发布截图主选 |
| F 品牌/章节色块 | 大色块横幅、极少字 | 章节停顿 ≤1 | 少用 | 可作速览分隔 |
| G 叙事/编辑插画/纸艺 | 按议题选择角色、媒介与色板；含纸艺、拟人编辑插画；**禁伪字** | 正文修饰可用；封面可按题选择，见下方条件 | 一般不用 | 少用 |
| H 3D 潮玩/卡通角色岛 | 卡皮巴拉岛、海洋粘土图标阵等 | **默认不用**（易广告/玩具感） | 不用 | 不用 |
| I 落地页英雄拼贴 | 多图标环绕、营销 Hero | **默认不用** | 不用 | 仅当文章主题就是落地页且作反例/案例时 |
| J 怪纹理/强滤镜抽象 | 难辨主体的纹理噪点 | **默认不用** | 不用 | 不用 |
| K 动漫/二次元主视觉 | 明显二次元角色主画面 | **默认不用**（除非选题本身是漫/二次元） | 不用 | 不用 |
| L 手绘草图流程 | 白板/Excalidraw 感：略抖墨线、粉彩圆角框、手写中文、白底；见 [CASE](visual-cases/hand-sketch-flowchart/CASE.md) | **说明图可用**（流程/结构/分工） | **可用**（须绑步骤） | **可用**（须绑证据） |

## 封面怎么选（01 默认仍只交一张主横封面）

选型条件统一在本节维护；17/18 与共享说明只作指向，不另立排他菜单。

- **默认优先 A 氛围摄影或 C 强标题设计。** 看本题读者需要认出什么对象、看懂什么关系，再决定主视觉。
- **主题强相关时可选 E 真实产品/界面图。** 保留真实来源，默认有设计感少字标题，除非用户明确只要无字。
- **角色、关系或对比能直接承载议题时，可选 G 编辑插画，含拟人化。** 参考[本轮正反案例](visual-cases/agent-homogeneity/CASE.md)的选择依据；角色或物件数量、媒介、色板、姿态与构图随题重选，不固定机器人或左字右图。单次认可不视为多题稳定验证。
- **H/I/J/K 仍默认不用。** 参考包里再好看也不自动进菜单。

按题选择不改变正文写实混搭默认，也不新增“先问能不能用插画”的停点；新视觉基准仍按既有流程首张交用户确认。

## 正文照片/图「要用什么」——一句话清单

| 段落在干什么 | 用什么 |
|---|---|
| 引入抽象议题、需要人在场 | B 真人实景/过肩（亮、有重点） |
| 讲步骤/工具链 | D 流程图、**L 手绘草图** 或 E 真截图 |
| 讲关系/对比/边界 | D 分栏或对比表；体系/分工可 **L** |
| 章节换气、无新信息 | A 或 F（一张够）或 G（禁伪字） |
| 引用官网能力 | E 官图/发布页；来源与核验日期留记录及文末，图注只留理解必需信息（见 [17](../17-长文配图-article-visuals/SKILL.md#读者面文案禁区)） |
| 「好看但说不清」 | **不加** |

同篇至少换 2 种用途或标签；忌张张书桌、张张白底卡、张张潮玩。

## 和旧图种菜单的关系

[17 长文图种菜单](../17-长文配图-article-visuals/SKILL.md) 仍然有效。本表是**风格层标签**；图种菜单是**结构层选型**。两者一起用：先图种（流程/情境/分栏…）再套风格标签（A–G，说明流程可 L），并执行 H–K 默认禁用。L **不是**禁用项。

## 提炼进 Skill 时怎么说清楚（给 Agent 的句式）

配图计划每行写成：

`图N｜用途=说明图｜风格=D｜存在理由=…｜插入=…节｜图注=…｜不做=H潮玩/假UI`

封面写成：

`C1｜用途=封面｜风格=按上方条件选定的标签｜默认有设计感封面字（少字、层级清）｜不做=H/I/J/K`

## 按入口绑图松紧（用户确认 2026-10-24）

| 入口 | 图与正文绑定 | 规则 |
|---|---|---|
| **01 深度观点** | **尽量绑定**，允许弱绑定 | 说明图（D/E/L）必须服务当节论点；修饰图（A/B/G）可用主题隐喻或情绪同场，**不要**完全跑题的桌面/风景。封面优先与议题同场（道具、场景、隐喻），不要求字面复述标题。 |
| **04 教程** | **必须强绑定** | 每张图对应具体步骤、界面、组件或检查项；禁止无关情绪大图占位。允许 0–1 张 B 仅作开篇带入。 |
| **05 资讯·调研** | **必须强绑定** | 官图、真机/发布截图、对比表、实测界面；禁止与产品/版本无关的氛围图充数。封面可用 C/E，须一眼看出在评什么。 |

计划行追加：`绑定=强|弱｜绑定对象=第N节论点/步骤K/产品功能X`

## 公众号封面字（用户确认 2026-10-24）

默认**要有字**，且须有设计感（参考包横幅的字重、层级、留白与主视觉关系；优例见 visual-good-examples）。经 16 定字 → 17/18 落版。禁止随便压一行无设计感黑字；伪字与制作元信息仍禁。
