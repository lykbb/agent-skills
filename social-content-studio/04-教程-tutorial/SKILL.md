# 教程入口（04）

与 [01 深度长文](../01-长文-long-article/SKILL.md)、[05 资讯·调研](../05-资讯调研-news-brief/SKILL.md) **平级**。文风对照见 [genre-defaults](../references/genre-defaults-01-04-05.md)。共享节点冲突时读 [冲突裁决](../references/design-article-ref-lessons.md#冲突裁决必读)；本入口默认**不得**推翻用户确认与 [pipeline](../references/pipeline-contract.md)。

沿用已确认题目、平台、步骤范围与材料。未定题按 [总入口选题规则](../SKILL.md#选题先确认)。只改某一步或一张图时直接处理指定阶段。

## 本入口风格（与 01 明显不同）

- **目标**：读者能按文完成一件事或验证结果。
- **结构**：前置条件 → 有序步骤（每步可验收）→ 翻车点 / 常见失败 → 完成标准。
- **语气**：「按这样操作」；哪里容易错就写哪里；允许短警告框感段落。
- **禁止**：升华成行业评论、老干部结尾、「综上所述三点启示」；禁止默认套用 01 的判断推进发动机与 ~5000 字目标。
- **字数**：够完成任务即可；用户指定篇幅优先。材料少就缩短步骤范围，不注水。

## 调用链

| 节点 | 调用与职责 | 本阶段应得到什么 |
|---|---|---|
| 材料预检 | 确认目标环境、版本、账号权限、可复现步骤材料是否够写 | 缺口清单；不足则收窄范围或补问（最多三问） |
| 12 | [选题大纲](../12-选题大纲-huashu-topic-gen/SKILL.md)：按本入口用 **步骤闸门**，不用深度观点发动机 | 步骤大纲、前置、翻车点、待核版本/路径 |
| 13（按需） | [调研核验](../13-调研核验-content-research/SKILL.md)：只核步骤依赖的官方文档、版本、路径 | 可写操作事实与未知项 |
| 审纲 | 交步骤大纲；**多问：是否写成了 01 观点文或 05 测评？** | 用户确认后写正文 |
| 14 | [正文写作](../14-正文写作-writing-skill/SKILL.md)：注明「教程」 | 可照做的正文；步骤编号清晰 |
| 16（可选） | [标题封面字](../16-标题封面字-title-creator/SKILL.md) | 标题承诺「能做成什么」，不装万字干货腔 |
| 独立文字验收 | 按 [独立验收](../references/pipeline-contract.md#作者自查与独立验收) | 步骤可复现、无假界面承诺 |
| 17（默认） | [配图](../17-长文配图-article-visuals/SKILL.md)：本入口配图默认见下 | 说明图计划；每图有存在理由 |
| 18（默认） | [生图](../18-生图制作-social-image-studio/SKILL.md) | 成图；截图类优先真截 |
| 交付复核 | 14 适用项 + [19](../19-发布复核-check-social-content-compliance/SKILL.md) | 说明真实完成范围 |

默认不走 01 的「反方压力测试 / 判断被材料改变」深度发动机。常青操作题可弱化 13；版本敏感步骤必须核官方文档日期。

## 配图与抓图默认

- **说明图为主**：真截图、少节点流程图、关键设置面板；**修饰图 0–1**（封面或章节停顿可选一张）。
- 每图仍须 **存在理由**；无理由不加。禁假 UI 冒充产品原图。
- **抓图**：官方文档图、用户授权环境实截；流程用 Mermaid / HTML 干净导出，禁止编辑器整窗当终稿。
- 细则仍读 17 图种菜单，但选型优先「流程 / 界面拼贴 / 单功能卡」，少用情绪大图与叙事插画。

## 审纲之后与交付

正文、标题回验后默认连续 17→18；跳过配图须用户当场拍板。成稿位置遵循 [总入口的 Notion 优先与本地兜底规则](../SKILL.md#保存与交付)，正文与实际配图一起交付。正文不加行动号召与互动引导（见 pipeline）。读者面不写制作元信息。

范围与停点见 [pipeline-contract](../references/pipeline-contract.md)、[checkpoints](../references/checkpoints.md)。

## 中文包提炼（2026-10-24）

来源与分类见 [chinese-pack-lessons](../references/chinese-pack-lessons-2026-10-24.md)。只补本入口特色，不推翻上文步骤闸门与禁升华硬规则。

- **步骤链偏好**：能写成「原则/约束 → 可复用 Skill 或检查清单 → 组件库/系统接入」时优先用此三截，每截写完成标准（参见落地页去 AI 味、UX Writing Skill 建置类范文方法）。
- **规范写法**：正反例 + 情境语调或状态矩阵写进可执行指引；禁止只剩散文心得。
- **翻车点**：AI 辅助步骤必写幻觉风险、人工核验节点、意外发现如何处理；作者口述效率数字**不作**基准数据。
- **截图规范**：真界面/授权环境实截；说明状态与确认点用少节点图；禁假 UI。
- **忌升华**：收束停在能做成什么、哪步易错；「N 条原则」只可作检查附录，不作教程主线目录（对齐冲突裁决）。

## AI Skill 参考库增量（2026-10-24）

来源与冲突跳过见 [ai-skill-ref-library lessons](../references/ai-skill-ref-library-2026-10-24-lessons.md)。只补缺口，不推翻步骤闸门与禁升华。

- **演示条件 vs 读者可复现**（翻车点）：配置/实测稿须在同屏区分「作者演示条件」与「读者可复现条件」；标题含极端配置（如低内存也能跑）时，正文首屏必须拆穿代价与硬件前提。
- **版本/阶段演进大纲**：架构或流程演进类教程，默认用「版本或阶段闸门」作步骤骨架；效率数字旁须有统计口径一句，否则标「作者自述」（与上文「不作基准」同向强化）。
- **开源 Skill/工具顺序**（与三截链同向）：效果证据 → **明确不做**的边界 → 安装与最小复现命令；禁止先长概念后无验收步骤。

### 维护 / 实跑注意（2026-10-24）

- 执行时核：演示 vs 可复现同屏；开源顺序「效果→边界→安装」；演进题用阶段闸门；禁升华尾与 CTA；效率数字旁置口径。
- 规则变更走 [skill-maintenance](../references/skill-maintenance.md)；烟测状态见 [ai-skill-ref-library lessons](../references/ai-skill-ref-library-2026-10-24-lessons.md)。正式发稿级（审纲+17→18）尚未压，勿把烟测当全链路验收。
