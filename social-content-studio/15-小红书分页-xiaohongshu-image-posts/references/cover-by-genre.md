## 联网取真素材（硬）

凡封面或内容页要用到下列任一元素，**必须先调研联网**（搜官网 / GitHub / 官方文档 / 应用商店页），取得可核对材料后再排版；**禁止凭空画假 UI、假菜单、假标签、假 star、假认证**：

- 官方 Logo / 字标
- 产品关键界面截图或关键按钮/菜单文案
- 仓库 README / docs 中的示意图、架构图、知识图谱形态
- 可核验的版本号、star 数、定价等动态数字（用时再核，不背旧数）

取到的素材在分页/交接里标明角色：`官图` / `仓库素材` / `实截` / `抽象自官图`。无材料则改纯概念卡或明确「示意」，不装真。

## 官图可弃（审美，用户已确认）

**取真 ≠ 必须塞一张官网图。未要求就不加图。** 联网取到的官网首页、营销长图、整页 README、「官方生成示例」全景等若不好看、构图脏、或不适合竖版缩略图，或用户/大纲**未点名**要演示大图：**不要硬塞**。优先：产品名 + 可见官 Logo、抽象界面元素、干净排版页；宁可留白。双图对照仅论证需要且点名时用。证据页（见下）≠ 默认贴官例全景+图下说明字；优先可用真界面截，其次 Logo 主导干净页；仍禁止假 UI 冒充「用过」。成图禁「官方生成示例」角标/横线解说（见 18 读者面文案禁区）。

## 真标签规则

- 菜单名、按钮文案、话题相关专有名词、界面专有控件名：**须来自实截或官方材料原文**。
- 无材料时：**不编**「看起来真」的假 UI 字、假角标、假「官方认证」、假数据徽章。
- 与 [pipeline 禁假来源](../../references/pipeline-contract.md) 一致：风格/密度问题不能靠假信息解决。

## 证据页（分页硬）

讲**具体产品 / 仓库 / 后台操作**时：整组至少 **1 页**能证明「见过真东西」（真界面可用截、Logo+名干净页、或用户点名的官例）；不得整组只有纯文本卡冒充「用过」。**不等于**默认塞「官方生成示例」全景/双图对照+说明字。  
纯观点 / 纯方法概念页：允许纯文本卡或概念图示，不强行贴无关官图；未要求配图就不加演示大图。

## 类型 → 封面默认

| 图文类型 | 封面主视觉 | 官仓/官网元素怎么用 | 少做什么 |
|---|---|---|---|
| **产品 / 工具介绍** | 产品名 + **可见**官方 Logo 或关键界面元素 + 一句话用途（缩略图能认出来是谁）；名与 Logo 可居中作主角，不限于左上刊头；**可选**少字骨架「名大字 / 一句品类 / Logo 居中 / 一句主张」（见 [CASE](../../references/visual-cases/xhs-first-gen-clutter/CASE.md)，**非全站默认**）；本品类避坑：刊头+多层标题堆（非全局硬禁） | Logo/关键截优先官源；与 18「产品介绍封面」句对齐 | 只靠角落小字交代产品名；AI 造假界面当主视觉；产品介绍上刊头再叠多层大标题（避坑） |
| **攻略 / 资讯** | **问题或收益标题**主导 | 真截 / 官图作**证据拼贴**（副视觉或内容页） | 大 Logo 墙、品牌海报感盖过标题收益 |
| **工具知识点 / 方法** | **概念关系或步骤**为主视觉 | 可用官仓示意图 **抽象**（去底、简化节点/连线、统一产线配色），保留可辨认的结构关系 | 整页 README / 整窗仓库截糊上当封面；重绘后仍声称「原截」 |

未点名类型时：先按内容判断偏产品介绍、攻略资讯还是知识点方法，再选上表一行；可与既有「软件介绍 / 合集 / 教程与知识图文」节合并执行，不另开第二套版式哲学。

## 官仓元素抽象（正例口径）

**允许**：从 GitHub / 官网 docs 取出示意图、知识图谱、架构节点，**去底、简化、重排节点标签为中文可读**，作为封面或知识点页的概念主视觉；交接角色写 `抽象自官图` 或 `抽象自仓库素材`。

**禁止**：把整页 README、星标墙、贡献者列表糊满当封面；把抽象图说成未改动的原截；为「更真」AI 生成假仓库界面。

**正例口径（只学方法，不锁版式/标题）**：知识点类可从项目 GitHub / docs 的知识图谱或架构图 **抽象** 成封面主视觉（去底、简化节点、中文可读），而非整页 README 截图。**不参考**某次用户成图的排版疏密、配色完成度或标题文案；封面大字与发布标题一律走 [16 标题封面字](../../16-标题封面字-title-creator/SKILL.md)，不从旧封面抄标题。学的是「官仓结构 → 抽象成概念图」这一招。

## 许可与署名

- 官图 / 仓库截图作**说明性**封面或证据元素；Logo **不改到认不出**（可变尺度、去底，不篡改成另一品牌）。
- 不把未授权商用素材库当默认可扒源；无把握时改自有生成/示意并标注，或只用可核验的官方公开页截图并保留来源说明（来源说明放聊天/正文，不强行小字塞满图面）。
