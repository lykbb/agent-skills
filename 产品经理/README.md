## Yukun 产品开发工作流

由 Yukun 负责流程设计、模块衔接、规则适配与持续维护。整包位于 `skills/yukun-product-workflow/`：立项报告与底稿 → 可实施 PRD → 架构蓝图 → 核心切片与界面联调 → 实际运行验收。三个模块随包提供，不需要分别安装；业务代码放使用者指定的独立项目。

已有资料和已定选择直接承接，已有项目从当前阶段继续。默认交付本地 MVP，发布上线另按授权；只要立项或方案时按当前范围停下。没有真实模型验证的部分保留待验，不能用静态或 mock 结果替代。

用法、包内检查和来源见 [整包 README](skills/yukun-product-workflow/README.md)。公开副本不包含真实 `.env`、Git 历史、私人运行产物、虚拟环境和固定个人路径；原模块教学/历史样例不代表整合版已完成真实业务验证。
