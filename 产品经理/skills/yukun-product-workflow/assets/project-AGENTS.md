# 项目约定

- 本目录是唯一业务工作区，代码和必要交付物留在此处；Skill 包仅作只读方法参考。
- 当前需求见 `docs/PRD/PRD.md`，阶段、已定决策与验证范围见 `docs/项目状态.md`；已有事实和授权沿用，不重复访谈。
- 用户当前指令优先。已有技术栈和目录保留；改动按影响做必要检查，不为模板重建工程。
- 不编证据、指标或完成状态；mock、静态、真实模型、浏览器操作和用户效果分别说明。
- 密钥只存本地排除的配置或 Secret，不进提交、前端、日志或截图。安装、费用、外部动作和文件删除覆盖按用户规则确认。
- 默认交付本地 MVP，真实核心闭环及必要失败路径实际验证后才报告相应通过。
- 保留代码、必要设计资料、启动 README 和状态；不默认追加过程回执或验证日志文件。
