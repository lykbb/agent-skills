# MVP 实施参考模块（整合版）

适配自 AI 产品开箱工具包，保留三份技术手册、参考代码、项目说明、通用图片与 MIT 许可。其职责是把已经确认的 PRD 和蓝图实施成可验证的业务闭环。

从 [产品开发总入口](../../SKILL.md) 进入，先读 [实施适配](../../references/execution-adapter.md)。本目录不能承载业务项目；原独立版的 `projects/`、固定云平台和启动句不是总包的运行要求。

`verify.sh` 已替换为指向总包标准库预检器的轻量适配器：必须显式传入独立业务目录和阶段，只输出 JSON，不运行项目代码或保存日志。完整 MVP 的运行、测试、模型和交互验收由编码 Agent 按实际项目执行，预检器不会宣布验收通过。

部署手册仅在用户明确要求上线后读取。手册里的模型、价格、额度、认证和平台操作属于历史参考；执行前核对当前官方资料和相应费用授权。未实际验证的能力不能声明已可用。
