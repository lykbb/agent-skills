## v1.1.0 · 2026-10-16

- 修改原因：用户认为普通模板约 2—3 分，外部 Bot 却给 4.30／4.00；旧锚点把基础规整、可替换与无明显错误当作优秀，容易整体抬分。
- 分档整改：3=普通合格，4=有具体优势的优秀，5=成熟示范；2 分须有明显设计弱点。逐维重写锚点，要求 4／5 说明超出基础合格的可见依据，不因普通视觉压低全部分项。
- 准入整改：A／B／D 均须 ≥4，适用于视觉及实用用途；C／E 实用下限仍为 3.5。总分不能补偿普通视觉。连续大量难替换指标的 C 上限从旧 3 调整为 2，保持“2=明显弱点”的新语义。
- 保留规则：25 个来源及原链接；权重 30／30／10／25／5；跨行业参考、栏目可替换、S≥4、置信度、30—40 试运行、人工验收后扩围、双用途及 Bad Case 留档。
- 修改前：[v1.0.0 快照](template-evaluation-history/v1.0.0.md)；修改后：[v1.1.0 快照](template-evaluation-history/v1.1.0.md)。
- 新规则 SHA-256：`fd4ce236cde72b030503b40285acd9fd55397df498195ca1ac5b27f5c42b4050`；旧版快照字节未改。
- 新案例：[B001](../assets/template-library/bad-cases/案例索引.md)。保留用户给出的总体 [2,3] 区间、原话及外部 Bot 两次评分截图，不取中点、不编人工分项；外部规则版本未知。
