# 固定评测集清单

当前状态：已冻结 1 个样本，固定集版本 bench-v1，人工标注版本 labels-v1。人工提供总体 2—3 分区间及质量不应达 4 分的判断；没有人工精确总分或分项，因此精确评分偏差和平均绝对误差不可计算。

冻结输入与答案见 [bench-v1 / labels-v1](sets/bench-v1-labels-v1.md)；新旧规则的同图检查见 [v1.1.0 运行记录](runs/v1.1.0-C001.md)。该图参与本轮规则制定，是开发集案例；即使评分输入隔离，也不能视作独立测试集。当前没有人工确认的正例，不能据此推断整体筛选效果。

最新回归：[v1.2.1 模板内容边界与 C001](runs/v1.2.1-C001.md)。固定输入与人工标签未变；澄清示例文案不参与模板质量扣分，C001 新评分仍为 3.00。6 个独立规则场景检查通过，未进行成对图片实验、全量重评或新搜索。

历史回归：[v1.2.0 检索规则检查与 C001](runs/v1.2.0-C001.md)，保留原记录。

本文件不是 Bot 自评样本清单。只有用户明确确认的评分或通过结论，才可作为人工答案；Bot 初评、用户未反馈、仅表示不喜欢都不能自动转成质量真值。

## 纳入与冻结

- 从已人工确认的 Good Case、Bad Case 和边界案例中选取固定样本。边界是附加标记，可同时属于 Good 或 Bad，不为此复制第三套模板。
- 保留实际检查的图片页面与校验值、原案例 ID、来源和人工答案。没有稳定实际图片时标待补齐，不把未来可能失效的链接当作已经冻结的图像输入。
- 每次比较锁定同一批中性样本 ID、相同图片页、固定集版本、人工标注版本与所依据的规则版本。加减样本或改标签必须生成新的相应版本，保留旧清单。
- 不在看到新版结果后挑选有利样本、删除误判、补造人工评分或修改旧答案。人工改变评价时另记新标注版本。
- 实际人工标签可以是区间或明确的用途结论；只用于其能支持的比较，不取中点、不反推分项。新增独立案例后再检查泛化，不把同图开发检查冒充独立验证。

## 冻结时每条记录

| 字段 | 内容 |
| --- | --- |
| 中性 ID 与原案例 ID | 对照步骤可追溯来源；评分输入不暴露 Good／Bad 目录名 |
| 样本角色 | Good／Bad，另可标边界；视觉／实用用途分别记录 |
| 固定图片 | 实际文件相对路径、已检查页、图片校验值、图像获取方式 |
| 人工答案 | 总分或已确认分项、各用途通过结论、具体理由；缺失字段留空 |
| 版本绑定 | 固定集版本、人工标注版本、人工评分依据的规则版本 |
| 人工确认状态 | 已确认及其时间／来源；未确认不进入冻结答案 |

## 版本测试

1. 评分者只看到中性 ID、固定图片和待测规则／Prompt；不读取本清单中的人工答案、原类别、旧分或旧理由。需要文件路径时可另存中性名称快照，避免路径名泄漏答案；快照不计新增模板数。
2. 先记录并固定新评分，再由对照步骤读取人工答案比较。检索时的案例校准和固定集回归是不同模式，不能把先看答案再评分称为盲测。
3. 使用相同样本比较旧／新版本，保留具体分数、通过判断、缺失项及配置差异。尽量保持模型与运行设置一致；有差异如实记，不能把换模型的影响全归功于 Prompt。
4. 记录平均有符号偏差、平均绝对误差和按用途划分的误通过个数／分母／比率。指标定义以当前模板规则为准，分母或人工分不足时写不可计算。
5. 改权重但维度含义一致、人工分项完整时，可以重算并登记派生标注版本；没有分项或定义改变时，须人工确认新答案，不能把旧总分直接当新标准真值。

新版平均分更高不构成改进证据。根据同集误差、误通过及具体案例作判断，存在取舍交人工复核；没有人工样本时只做规则结构与场景检查，不声称图片评分效果已验证。
