# 地标摄影与复古插画对照海报

先确定地标、观景方向和这轮要交付的内容。有照片就把该照片作为内容依据。用户只要摄影图、插画、局部排字、拼版或提示词时，直接做该阶段。没有照片时也可单做插画。若要和特定照片组成对照海报，用那张照片作改绘输入。延续一组海报时，沿用已认可的版式与画法。

## 准备摄影图

- 用户提供照片时，确认地标、视角和画质。拼版时直接使用选定照片。裁切若有必要，保留主体识别特征和关键前景。
- 用户要生成摄影风素材时，先确定一个具体机位。从景区、博物馆或图注明确的公开实景核对地标轮廓、主体排列和前中远景关系。山地看峰序、山脊、谷地。建筑看屋顶、台基、城墙和水岸的位置。用户已经认可的摄影素材可直接用于改绘。
- 以核对后的实景为构图依据生成一张摄影图。先检查能否辨认地标及机位，明显偏离时先修摄影图。交付时区分用户提供的实拍与 AI 生成的摄影风图。使用第三方照片作交付素材时，记录其来源和适用的署名或许可。

## 从摄影图改绘

用选定的摄影图作为图像编辑输入。若另有风格参考，明确其只提供笔触、配色和排版。先辨认摄影图中最容易识别的两到四个地貌或建筑特征，写进提示词并用来验收。优先保留拍摄方向、主体轮廓、相对位置和关键前景。为了给标题让位，可以等比缩小并略移整组景物。

> 把第一张图改绘成一张横版复古丝网印刷插画。保留照片中的【主体与视角】、【轮廓与位置关系】和【关键前景】。用粗细有变化的深色墨线勾勒，简化细碎纹理，用暖白、蓝灰、赭金等平涂色块表现光影。天空化为暖白纸面，主体后加局部半调网点，可用一枚小暖色圆点点缀。画面略向右收，左上留出连续纸面。输出单张插画，左上文字按给定内容排印，未给文字时留白。

需要地名版时，左上用醒目的宋体地名，下方用小字标地区和机位。可用一枚小朱印标地域或旧称。用户已认可无字底图并只要求加文字时，从该底图做局部编辑。逐字核对地名、机位和印章，确认文字与山脊、屋檐等轮廓之间有间距。示例文字「故宫」「北京 · 东城」「西北角楼」，朱印「紫禁城」。

## 拼版与验收

两张素材分别定稿后再做像素拼接。上半放选定摄影图，下半放同一画面的插画。小红书竖版默认 3:4，两张横图各为 3:2 且等宽等高。可直接把两张 1536 × 1024 图拼成 1536 × 2048 PNG，或按用户要求输出 1080 × 1440 等尺寸。源图尺寸或比例不同时，先确定合适的裁切或留边，避免拉伸。

已装 FFmpeg 时，标准等尺寸拼版可运行以下命令。脚本也需要同套安装的 ffprobe。输入路径顺序即上下顺序。

```bash
python3 scripts/stack_poster.py "摄影图.png" "插画.png" "对照海报.png"
```

对照检查主体特征能否一眼认出，图内字是否清楚，边缘有没有裁掉重要信息。检查成品尺寸、拼接顺序和接缝。若用户要分享提示词，交付实际用到的改绘提示词，并写明先选定摄影图、再改绘、最后上下拼版。
