## 独立规则场景检查

检查者只接收新规则，不接收案例图片、人工标签或历史分。六个实际结论如下：

| 场景 | 检查结论 | 结果 |
| --- | --- | --- |
| 版式相同，仅换成 Lorem／YourName 或矛盾日期 | 不因语义变化降低 A—E | 通过 |
| 日期的连接符、字面写法不同，换文案即可统一 | 不单独扣 B，只记替换备注 | 通过 |
| 日期确被挤断，导致角色归属混淆 | 可按具体视觉影响据 B 评分，避免重复扣分 | 通过 |
| 技能条示例均为 50%，可换为文字且不损失容量 | 不因数值无能力依据扣 B，也无此项 C 扣分依据 | 通过 |
| C 容量或 E 伸缩规则没有足够证据 | 待核实；有未知维度不算完整 S、不正式推荐，不自动给低分或 4 分 | 通过 |
| 开始编写用户正式简历 | 仍核验真实经历，不能沿用示例内容豁免 | 通过 |

6／6 通过仅表示规则理解一致；没有渲染“相同版式、不同文案”的成对图片，不能声称实际视觉评分的语义不变性已经验证。
