## 在线模板网站

### 免费
- **Markdown 简历**：https://www.markdownguide.org/markdown-resume/ — 纯文本，ATS 最友好
- **Canva**：https://www.canva.com/resumes/templates/ — 大量设计模板，免费版够用，适合设计/市场岗
- **知乎 / 站酷**：搜"简历模板"，有很多设计师分享的免费 PSD/Figma 模板

### 付费 / 高级
- **Novoresume**：https://novoresume.com/ — 海外知名，ATS 友好校验，免费版基础功能够
- **Enhancv**：https://enhancv.com/ — 视觉效果好，适合创意岗位
- **超级简历**：https://www.wondercv.com/ — 国内产品，中文模板多，免费版有水印

## 按场景推荐

### 国内互联网 / 大厂求职
- **首选**：超级简历 / 知页简历 — 中文模板贴合国内 HR 审美
- **风格**：极简黑白，单栏，不要花里胡哨
- **避坑**：不要用照片、不要用彩色背景、不要用图标堆砌

### 海外 / 外企 / 留学申请
- **首选**：Awesome CV / AltaCV（LaTeX 模板）— 专业、ATS 友好
- **风格**：单栏，经典衬线字体，不要侧栏
- **避坑**：不要放照片、不要放年龄性别、不要写"期望薪资"

### 技术岗（程序员 / 算法 / 数据）
- **首选**：GitHub 上的 Markdown / LaTeX 模板
- **特点**：技术栈放最前面，项目经历写清楚技术选型和成果
- **加分**：附上 GitHub 链接、个人博客链接

### 设计 / 创意岗
- **首选**：Canva / Figma 社区模板
- **特点**：可以有设计感，但要控制在 1-2 页
- **加分**：附作品集链接（Behance / 站酷 / 个人网站）

### 应届生 / 校招
- **首选**：超级简历 / 500强简历模板
- **重点**：教育背景放前面，实习经历放核心位置
- **避坑**：不要写校园经历流水账，挑 2-3 个最有亮点的写
