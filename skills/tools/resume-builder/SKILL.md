# Resume Builder

## Overview

一站式简历工具：搜模板 + 写内容 + 优化打磨。覆盖中英文场景，兼顾 ATS（招聘系统）友好度。

---

## 任务一：找简历模板

当用户问"有没有简历模板推荐"、"什么风格的简历好"时，按以下流程：

1. **先问清楚关键信息**（如果用户没说）：
   - 国内还是海外求职？
   - 什么岗位方向？（技术/产品/设计/咨询/应届生）
   - 喜欢什么风格？（极简/创意/学术/互联网风）

2. **推荐模板来源**：读 [references/resume-templates.md](references/resume-templates.md)，根据用户场景挑 2-3 个最合适的，直接给链接和特点说明。

3. **如果用户要可直接用的模板文件**：从 `assets/` 里取 Markdown 模板，或者基于 references 里的推荐帮用户生成。

---

## 任务二：写 / 优化简历

当用户要写简历、改简历、润色简历时：

### 第一步：收集信息

先问用户要这些信息（缺什么问什么，别一次问太多）：
- 目标岗位 + 公司类型（大厂/外企/创业公司）
- 工作年限 / 应届
- 教育背景
- 工作/实习经历（公司、职位、时间、做了什么）
- 项目经历（可选但加分）
- 技能栈
- 中英文需求

### 第二步：按标准结构输出

读 [references/resume-guidelines.md](references/resume-guidelines.md)，按以下结构组织：

```
1. 基本信息（姓名、联系方式、LinkedIn/GitHub 可选）
2. 个人总结 / 职业概述（2-3 行，可选，有经验者建议加）
3. 工作经历（倒序，每段：公司 + 职位 + 时间 → 3-5 条 bullet points）
4. 项目经历（如果项目比工作更亮眼，放在工作经历前面）
5. 教育背景
6. 技能 / 证书
```

### 写作原则（必须遵守）：

- **bullet points 用动词开头** + 量化成果（`提升了 X%`、`服务了 Y 用户`、`效率提升 Z 倍`）
- **不要用"负责"、"参与"这种弱动词**，换成"主导"、"搭建"、"优化"、"推动"
- **每条不超过 2 行**，一句话讲清"做了什么 + 结果是什么"
- **一页纸原则**：5 年以内经验控制在 1 页；超过 10 年最多 2 页
- **ATS 友好**：避免用图片、表格、奇怪字体；标题用标准的 "Experience"、"Education" 这种词

### 第三步：交付

- 默认用 Markdown 格式输出，方便用户复制到任何地方
- 如果用户要 Word/PDF，提醒他可以用 Markdown 转（或者用 assets 里的 HTML 模板打印成 PDF）

## 注意事项

- **不要编造经历**：用户没说的信息不要瞎编，用占位符标出来让用户填
- **中英文语气不同**：中文简历偏正式简洁；英文简历要更"action-oriented"，动词更有力
- **不要套话**：什么"吃苦耐劳"、"团队合作精神"这种废话别写，用事实和数据说话
- **隐私**：不要把用户的简历内容发给任何外部服务，全部在本地处理
