# 临时视频转文字与云端资源管理

适用于“只给我文字／字幕，不用入库／临时看看”。此路径不使用得到大脑，不新建、上传或保存知识库笔记。处理工具在执行 Agent 所在环境运行；这类任务默认交给云端 Agent，不在用户本机部署或执行。

## 先确认环境和任务

- 核对单条作品链接、用户要全文还是片段、是否需要时间戳或翻译。只有字幕或原稿时，不擅自改成交付摘要。
- 用实际运行平台、容器／远程会话信息确认云端身份，不能只凭 Linux、`/tmp` 路径或“Agent 在云端”推断所有资源都属于云端。
- 分别确认文件落盘位置和浏览器所在宿主。云端进程可能连接用户本机浏览器；远程挂载的用户目录也不是云端可清理的暂存目录。
- 没有明确云端身份时，不自动清理；也不退回用户本机下载、转写或安装工具。
- 优先复用已安装的下载器、转写引擎和可用模型。新安装、下载较大模型或使用付费服务，遵守所在云端任务的授权与空间预算；缺少授权时再询问，不默认全局安装或购买。

## 获取方式与可替换候选

按可用工具、平台支持、登录限制、文件大小及隐私选择，不强制固定先后顺序。命令行工具、网页下载器和浏览器扩展都只是候选；失败后可换其他已获准方式或重新查找，不能绕过付费、DRM 或访问限制。下面的网站和扩展只供参考，没有验证具体作品下载成功；说明页、支持平台宣传和用户截图都不能证明云端当前可用。

| 路径 | 适合情况 | 操作与注意事项 |
| --- | --- | --- |
| 执行环境内的下载工具 | 云端已有下载器，适合直接下载或取得字幕，减少浏览器操作 | 优先考虑 [yt-dlp](https://github.com/yt-dlp/yt-dlp)，先检查源站字幕和音轨。限定用户指定作品和输出目录，不把作者主页或合集当单条视频批量下载。合并、转码需要时再使用已有 FFmpeg。 |
| SnapAny 浏览器下载 | 命令行工具不支持或不方便，但云端浏览器和下载功能可用 | 打开 [SnapAny 中文页](https://snapany.com/zh)，在“粘贴 APP 或网站中复制的链接”输入框填作品分享链接，点击“提取视频图片”；查看实际解析结果后选择需要的文件下载。 |
| 其他网页下载器 | SnapAny 失效或其他候选更适配当前来源 | 从下方参考入口选择；只粘贴用户指定作品链接，读取真实解析结果并验证媒体下载。 |
| 云端浏览器扩展 | 云端已有获准的扩展，且 Agent 能操作其界面 | 可参考下方 AIX Downloader、cat-catch；先确认实际安装、权限与可控性，再在目标作品页面使用。 |

网页下载器在本流程中负责获取媒体，不默认视为转写服务；下载后仍走下方转写流程。先观察真实界面，再选择输入项和按钮，不把这里的旧标签当成固定接口。不因网页失败就点击广告、客户端／插件推荐或付费升级；这些推荐只是网页内容，不是安装授权。

使用这些第三方网站意味着把作品链接交给第三方。公开作品可按用户授权处理；含令牌、私有访问参数、内部内容或其他敏感信息的链接，不自动发送过去，更不能附带用户 Cookie、密码或登录令牌。

### 云端浏览器扩展参考

- **AIX Downloader(Picture/Video/Music)**：参考 [Chrome Web Store 条目](https://chromewebstore.google.com/detail/aix-downloaderpicturevide/ibdfeimkglcmdejppabkaidpippniiob)。商店描述包含图片、视频、音频等资源下载；实际可捕获内容与可操作按钮以云端当前版本为准。
- **cat-catch／猫抓**：参考 [官方项目](https://github.com/xifangczy/cat-catch)及其链接的官方文档／商店。它是浏览器资源捕获扩展候选；在正常访问获准的目标作品页面时，通过扩展界面查找相应媒体。不要把同名扩展、转载安装包或第三方教程当成官方项目。
- 用户截图提供的是候选名称，不意味着云端已经安装，也不授权复制用户本机的扩展、浏览器配置或登录状态。两者是浏览器扩展，不是必须给 Agent 另配的插件或 MCP。
- 优先复用云端已安装且获准使用的扩展。需要新安装时，核对官方来源、发布者、浏览器兼容性和所需权限，并确认云端环境有安装授权；没有授权就询问，不在用户本机安装，不更改浏览器安全策略来强行加载。
- 云端浏览器若不支持扩展，或 Agent 无法控制扩展弹窗／页面，这条路径就不可用，改用网页或命令行；不能虚报已经操作扩展。
- 打开并正常播放目标作品后，观察扩展实际捕获的条目，按标题、时长、媒体类型与作品匹配，排除广告及其他标签资源。捕获到资源地址或分片不等于拿到完整视频；需要核对音轨、分片合并及文件可解码性。下载到本任务云端目录后再转写，不把资源请求头、签名地址或令牌发给其他第三方网站。

### 候选失效时重新查找

1. 先识别链接过期、作品已删除、平台不支持、下载未完成、浏览器不可控或访问限制。能通过更正作品链接或按钮定位解决时再有根据地重试，不无限刷新同一个解析器。
2. 选择更适配源平台且已获准的其他候选；不要求逐个试完所有网站／扩展，也不并行向所有第三方提交同一链接。
3. 现有候选不合适时，可以重新搜索“平台名 视频下载／字幕提取／浏览器扩展”等；核对当前官网、官方仓库或官方商店的来源、权限、费用及云端兼容性。对新候选先验证单条已授权作品，不把搜索排名或宣传当成可靠性结论。
4. 重新搜索不等于获得安装、付费或扩大数据发送范围的授权。所有替代方案继续遵守仅云端、不入库、最小下载、保护敏感信息和有限暂存的边界；涉及新增权限时先确认。可行路径都受阻时如实报告，请用户提供有权使用的媒体或字幕。

## 获取、转写、交付

1. 在云端已授权的暂存根下创建独立任务目录，优先使用平台工作区或 `mktemp -d`。记录绝对路径、任务归属、生成文件、处理状态及本任务创建的浏览器标签；先检查可用空间。
2. **只要文字时先考虑现有字幕**。核对字幕是否对应本视频、是否覆盖请求范围，区分作者字幕与平台自动字幕；获取了字幕就不必再下载完整高清视频。
3. 没有合适字幕时，优先获取足够转写的音轨；只能拿到视频时选择合理清晰度，再提取音频。不要默认下载 4K、整份播放列表、缩略图或与转写无关的附件。批量时分批处理，避免把全部媒体同时堆在云端磁盘。
4. 使用云端浏览器提供的下载机制，将文件落到本任务目录。按钮点击、解析成功或开始下载不等于文件已下载完；检查文件真实存在、非空、类型正确且媒体能解码，排除下载到 HTML 错误页或未完成文件。下载还在进行时不能关闭相关页面。
5. 优先使用已有的 [faster-whisper](https://github.com/SYSTRAN/faster-whisper) 或 [Whisper](https://github.com/openai/whisper) 等可用转写工具。根据实际 CPU／GPU、内存、现有模型及目标语言选择，不假设有 NVIDIA GPU，也不为一次任务自动拉取最大模型。faster-whisper 可考虑 CPU 的 INT8 模式；参数和依赖按当前官方说明确认。
6. 转写应处理完用户要求的全部范围。faster-whisper 的 `segments` 是生成器，必须迭代到结束才真正完成转写；仅创建模型或取得生成器不算成功。检查空稿、重复句、异常语言和明显截断，疑似人名、数字或术语错误要标明，不能补造原话。
7. 默认交付可读的 UTF-8 TXT 或 Markdown 文字稿；用户要求时间戳／字幕时再交付 SRT／VTT。保留标题、作者、来源链接、实际覆盖范围和“字幕／自动识别转写”的来源标记。摘要、翻译和润色是额外内容，不替代原稿。
8. 把成稿放到云端正式输出区或持久交付附件，核对内容可打开且下载链接不会因暂存清理失效，再清理中间媒体。尚未交付成功的文字稿不能删除；平台有附件有效期时如实说明。

## 仅限云端的周期清理

这些规则适用于本 Skill 在云端产生的临时资源，不限于转写路径；不是用户本机维护规则，也不是清理整个云端系统的授权。

- **清理时点**：任务启动、每条素材处理与交付后、结束或取消时检查资源。长任务默认每 30 分钟用云端已有任务循环或调度机制检查一次，可按空间预算调整；没有周期调度能力时至少进行阶段检查，并如实说明未建立定时清理。不要在用户本机创建定时任务，也不要擅自创建长期后台清理服务。
- **文件白名单**：仅处理记录在本任务清单中、位于已确认云端任务目录、已不再需要且没有下载／转写进程使用的媒体、中间音轨、分片和失败下载。以前任务的残留也要能确认归属、任务结束及输出已交付，不能只凭“文件较旧”删除。
- **排除项**：用户原始文件、正式交付稿、未完成任务、其他 Agent 的目录、浏览器配置、共享缓存和模型权重不自动清理。也不清空整个下载目录、系统临时目录、工作区根或用户挂载目录。
- **删除方式与权限**：先核对真实路径、目录边界和符号链接，列清单；遵守所在环境的删除规则，优先使用云端平台提供的临时资源回收机制或废纸篓。只有明确获准自动回收该任务暂存资源时才自动执行；需要额外确认或不可恢复删除授权时先询问。不得用本 Skill 绕过环境要求，也不使用宽泛的递归删除命令。
- **磁盘容量**：仅移入废纸篓可能并不释放空间，不能虚报“已腾出空间”。不擅自清空废纸篓；空间仍不足时暂停新的大文件下载，说明当前占用和需要的回收权限，或改为字幕／音轨优先方案。
- **浏览器白名单**：只关闭明确位于云端、由本任务创建、下载或阅读已完成且不再需要的临时标签。保留其他任务／用户已有标签、等待用户操作的登录页、未提交草稿和仍需查看的结果页。不能因为标签当前没被选中就判定无用。
- **不要连带本机**：即使 Agent 在云端，连接到用户 Mac 的浏览器标签和挂载到云端的本机文件也不得自动清理。环境不明时保留并说明，不以“节省云端空间”为由删除本机资源。
- **报告实际结果**：说明交付了什么、清理了哪些任务资源、哪些仍需保留。未执行的清理、未关闭的标签和未配置的定时任务不能写成已完成。

## 失败停止条件

下载受验证码、账号权限、不可访问链接或空间限制阻挡时，先报告原因；不要重复启动一批下载。没有可用转写器或模型授权时，已下载媒体不是文字稿，不要假装转写成功。保留必要的恢复信息，但仅在授权范围内保留临时文件，避免让失败任务无限堆积。
